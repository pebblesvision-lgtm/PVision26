1. Photo

Photograph the stone face square-on if you can, with a reference of known size lying flat in the same plane as the face you want to measure: an A4 sheet, a printed marker, or a ruler.

Drop a photo here or click to choose
JPEG / PNG / HEIC-converted, up to 60 MB

Need a marker? Download a 100 mm ArUco marker and print it at 100%. Check the printed size with a ruler before use.

    5. Measure & register

    Click two points for a dimension (snaps to outline corners). The photo value is filled in; type the tape-measured value next to it to register it. The registered value goes on the drawing, the photo value is kept for reference.
